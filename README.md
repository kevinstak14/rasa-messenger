# رسا (Rasa) — پیام‌رسان محلی

رسا یک نمونهٔ اولیهٔ پیام‌رسان فارسی و راست‌چین است. سرور روی خود گوشی و داخل Termux اجرا می‌شود و اپ اندروید از طریق `127.0.0.1:3000` به آن وصل می‌شود؛ بنابراین برای گفت‌وگو روی همان گوشی به اینترنت نیاز نیست. برای گفت‌وگو بین چند گوشی، هر گوشی باید به سروری که از طریق شبکه قابل دسترسی است متصل شود؛ این تنظیم در نسخهٔ فعلی آماده نشده است.

> **وضعیت نسخه:** ورود آزمایشی، پروفایل پایه، فهرست گفت‌وگو، پیام متنی، آپلود/دانلود فایل، جست‌وجوی کاربران، واکنش پایه، ویرایش/حذف پیام و تم‌های روشن/تیره/آبی شب/AMOLED پیاده‌سازی شده‌اند. تماس WebRTC، ضبط صدا، استیکر/GIF، نظرسنجی، مکان، پوشه‌ها/آرشیو/مسدودسازی، پیام زمان‌بندی‌شده، خودتخریب‌شونده، رمزنگاری سرتاسری، رسید خواندن کامل و فونت‌های محلی در این نسخه پیاده‌سازی نشده‌اند. دکمهٔ تماس صرفاً وضعیت غیرفعال را اعلام می‌کند.

## پیش‌نیازها

- حساب GitHub و فعال بودن GitHub Codespaces
- گوشی اندرویدی ARM64
- نصب Termux از منبع معتبر و به‌روز
- برای کامپایل `better-sqlite3` در Termux ممکن است ابزارهای ساخت لازم شوند: `clang`, `make`, `python`

## بخش ۱ — ساخت APK در Codespaces

1. مخزن را در GitHub باز کن و از مسیر **Code → Codespaces → Create codespace** یک Codespace بساز.
2. صبر کن تا دستور `codespace/setup.sh` تمام شود. در اولین اجرا دریافت Flutter و وابستگی‌ها ممکن است بیشتر از چند دقیقه طول بکشد.
3. در ترمینال Codespaces اجرا کن:

   ```bash
   bash codespace/build-apk.sh
   ```

4. پس از پایان موفق build، فایل `rasa.apk` در ریشهٔ پروژه ساخته می‌شود.
5. در Explorer روی `rasa.apk` راست‌کلیک کن و **Download** را بزن.
6. فایل را به گوشی منتقل و نصب کن. اگر اندروید اجازه خواست، اجازهٔ نصب برنامه از همان منبع را فعال کن.

APK برای `arm64-v8a` ساخته می‌شود و روی شبیه‌سازهای x86 اجرا نمی‌شود.

## بخش ۲ — اجرای سرور در Termux

1. پوشهٔ `server/` را از مخزن دانلود کن و به حافظهٔ گوشی منتقل کن. اگر ZIP کل مخزن را دانلود کرده‌ای، مسیر پوشه را مطابق محل استخراج تنظیم کن.
2. Termux را باز کن و اجرا کن:

   ```bash
   pkg update -y
   pkg install nodejs-lts unzip git clang make python -y
   termux-setup-storage
   ```

3. اگر فایل ZIP در Downloads است، نمونهٔ زیر را اجرا کن (نام ZIP را با نام واقعی فایل جایگزین کن):

   ```bash
   mkdir -p ~/rasa
   unzip ~/storage/downloads/rasa-messenger-main.zip -d ~/rasa
   cd ~/rasa/rasa-messenger-main/server
   bash start.sh
   ```

   اگر فقط پوشهٔ `server` را استخراج کرده‌ای، مستقیماً وارد همان پوشه شو و `bash start.sh` را اجرا کن.

4. اجرای اول وابستگی‌ها را نصب و داده‌های نمونه را ایجاد می‌کند. پس از نمایش پیام «رسا آماده است»، برنامهٔ اندروید را باز کن.
5. برای ورود آزمایشی از یکی از شماره‌های نمونه استفاده کن:

   - علی: `09120000001`
   - سارا: `09120000002`
   - رضا: `09120000003`
   - کد آزمایشی: `123456`

6. برای توقف سرور در Termux کلید `Ctrl+C` را بزن. تا وقتی سرور در حال اجرا نباشد، اپ پیام «سرور روشن نیست» نشان می‌دهد.

## ساختار مخزن

```text
rasa-messenger/
├── server/       # Express, Socket.IO, SQLite و رابط وب محلی
├── app/          # Flutter WebView wrapper و تنظیمات Android
├── codespace/    # نصب و ساخت APK
├── .devcontainer/
└── README.md
```

## نکات امنیتی و محدودیت‌ها

- کد OTP برابر `123456` فقط برای توسعه است؛ ارسال پیامک واقعی وجود ندارد.
- مقدار `JWT_SECRET` در `.env` نمونه است. برای استفادهٔ واقعی آن را با مقدار تصادفی و خصوصی عوض کن و فایل `.env` را منتشر نکن.
- سرور روی `0.0.0.0:3000` گوش می‌دهد تا در صورت نیاز روی شبکهٔ محلی قابل دسترسی باشد؛ API فعلی برای اینترنت عمومی یا استفادهٔ چندکاربرهٔ امن سخت‌سازی نشده است.
- فایل‌های آپلودی فعلاً احراز مالکیت/محدودیت نوع فایل پیشرفته ندارند. فایل ناشناس دریافت نکن.
- پیام‌ها در SQLite به‌صورت متن ساده ذخیره می‌شوند؛ این پروژه رمزنگاری سرتاسری ندارد.
- اتصال `127.0.0.1` یعنی خود همان گوشی. نصب APK روی گوشی دیگر، آن را به سرور گوشی اول متصل نمی‌کند.
- برای پایدار ماندن سرور، محدودیت‌های باتری Termux را بررسی کن؛ بستن Termux یا توقف پردازش، سرور را خاموش می‌کند.

## عیب‌یابی

- اگر `better-sqlite3` نصب نشد: در Termux `pkg install clang make python -y` را اجرا و دوباره `npm install` را امتحان کن.
- اگر پورت اشغال بود، مقدار `PORT` را در `server/.env` تغییر بده و همان پورت را در `app/lib/main.dart` نیز عوض کن.
- اگر APK نصب نشد، مطمئن شو دستگاه ARM64 است و فضای کافی دارد.
- اگر صفحهٔ سفید دیدی، ابتدا در Termux سلامت سرور را بررسی کن: `curl http://127.0.0.1:3000/api/health`.
